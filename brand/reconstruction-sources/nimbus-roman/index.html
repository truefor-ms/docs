Nimbus Roman provenance

Pinned font inputs, upstream origin and preserved license notices.

Source record2026-11-05Markdown source
On this page

    The complete logo is rebuilt from Nimbus Roman Regular font outlines, rather than copied from the approved logo SVG. These files are build inputs, not web fonts to ship with the logo. The generated SVG has no runtime font dependency.

    Upstream: ArtifexSoftware/urw-base35-fonts.
