# Reconstructed Trueforms icon and complete logo

This is a separate reconstruction of the standalone icon from master handoff v2 measurements. It does not replace the approved source artwork.

The nine letters are regenerated from the [pinned upstream Nimbus Roman Regular font](../reconstruction-sources/nimbus-roman/README.md). Native AFM pair kerning is applied first, then the handoff's eight additional pair adjustments. The period glyph is outlined independently and centered at the specified B position between r and m; it does not add advance width to the word. The icon is generated by the existing independent construction script and placed at 0.75 scale with a 28.5-unit visible gap to the wordmark.

This uses the specified font's actual contours, not hand-drawn approximations. Neither the approved complete-logo SVG nor its path strings are inputs to generation. The approved B file is read only by the post-generation comparison. All output paths are outlined; the result needs no installed fonts. Source and generated coordinate systems differ through a consistent translation to a zero-origin viewBox.

To rebuild the SVG from the docs repository, install the pinned Python build dependency into your preferred environment, then run:

```powershell
python -m pip install -r brand/scripts/requirements-reconstruction.txt
python brand/scripts/recreate-logo.py
```

The preserved font, metrics, and upstream license files are build sources. No original handoff files are modified.

## Construction

The script does not read, import, or copy an existing SVG or its path strings. It constructs four paths from named measurements: a 96 × 128 centerline document, a 32-unit fold, four rows with 20-unit spacing, and a detached checkmark with 14/26-unit diagonal runs. Stroke width is 6.5, with round caps and joins; color is `#16765C`.

The measurement tables and path descriptions in master sections 03–05 were consulted. The 10-unit outer turns and 8-unit fold turn were interpreted from the specified control-point geometry. This is an independently implemented reconstruction from the supplied specification, not a claim that the original path definitions were never seen.

The output uses a normalized `0 0 102.5 134.5` viewBox. Every coordinate is rebuilt in that normalized frame, so the original translation is unnecessary. The outer contour is traversed in the opposite direction and the quadratic turns are represented by mathematically equivalent cubic curves. No source `d` string is reused.

The original icon is used only by the separate verification step after generation. Rendering differences, if any, are reported rather than hidden by modifying the reference.

## Regenerate

From the docs repository:

```powershell
python brand/scripts/recreate-icon.py
```

The icon SVG generator uses only the Python standard library. Both generators and all their inputs are kept in the docs repository; the UI repository is reserved for actual UI components. PNGs are rasterized previews of the generated SVGs, not traced or edited copies of the original images. The comparison reports record renderer and reference details.

The preview background is presentation only; the SVG and transparent PNG contain no background. For inline decorative use, the consuming component should hide the SVG from assistive technology; for an external image, supply the appropriate `alt` text.
